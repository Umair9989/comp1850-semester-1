# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | List everything in the current directory |
|     cd directory_name       | Changes the currenty directory to the one specified by 'directory_name' |
|     cd ..                   | Move up one directory level|
|     cd -                    | Returns you to the previous working directory |
|     mkdir directory_name    | Makes a new empty named directory |
|     touch filename          | Makes a new empty file |
|     git status              | Shows the current state of your current repository to your last save point |
|     git add -A              | Tells git you have made changes you want to save, '-A' is an option to show all |
|     git commit -m ""        | Bundles the changes, you can go to previous commits so is a save point, '-m' is an option which allows you to commit a message |
|     git push                | Sends the message back to the remote GitHub server |
|     git pull                | Fetches updates from a remote repository and merges them into the branch |
